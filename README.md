# 「单通哥杯」成绩公示

一个纯静态的成绩公示页面：`index.html` + `data.js` + 若干截图，无后端、无依赖、无第三方脚本。

## 更新成绩（日常只需要这两步）

1. 打开桌面的 `单通哥杯.xls`，把新投稿加进去，**保存**（Ctrl+S）
2. 双击本文件夹里的 **`同步并发布.bat`**

它会自动读表格 → 重新生成 `data.js` → 提交并推送到 GitHub。
等 1 分钟左右网页就会更新（浏览器里按 **Ctrl+F5** 强刷）。

窗口里会显示「成绩条数：244（原来是 243，新增 1）」，看到这句就是成功了。

> 网络偶尔会断，脚本会自动重试 3 次；要是最后仍失败，网络恢复后再双击一次即可，
> 它会接着把没推上去的提交推上去。

## 文件说明

| 文件 | 作用 |
|---|---|
| `index.html` | 页面结构、样式、表格渲染脚本 |
| `data.js` | 成绩数据（**由脚本生成，不要手改**） |
| `sync_from_xls.py` | 桌面 xls → data.js 的转换脚本 |
| `同步并发布.bat` | 一键「生成 + 上传」 |
| `发布.bat` | 只提交上传（改了 index.html 后用这个） |
| `origin.jpg` | 赛事起源截图 |
| `newrules.jpg` | 「新单通哥杯」新规则视频截图 |
| `intro-video.jpg` | 《单通哥传奇》视频截图 |
| `intro-account.jpg` | 单通哥当前账号名称截图 |

## 常见情况

| 提示 | 说明 |
|---|---|
| 已经是最新版本，不需要上传 | 表格没改，或上次已经传成功了 |
| 找不到置顶行 | 表格里「龙王 / 2命 / 62366 · 植2bug必须修」那条被删了或改了 |
| 表格被 WPS/Excel 打开着 | 没关系，脚本读的是副本 |

## 本地预览

在该目录下执行 `python -m http.server 8000`，然后访问 <http://127.0.0.1:8000/>（直接双击 `index.html` 也能看，但 `data.js` 在部分浏览器下可能被拦截）。

## 发布

仓库根目录即为本目录内容，GitHub Pages 选择 `main` 分支、`/ (root)` 即可。
`*.xls / *.xlsx / *.csv`、`发布.bat`、`同步并发布.bat`、`sync_from_xls.py` 已在 `.gitignore` 里，不会上传。
