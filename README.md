# 「单通哥杯」成绩公示

「单通哥杯」单人无限能量挂元素打桩 —— 娱乐赛成绩公示页面。

纯静态页面，无后端、无依赖、无第三方脚本。

## 说明

- 成绩为参赛者投稿记录，不代表任何角色强度，不构成抽卡建议
- 同一角色、同一套规则下的数字，只在本次规则范围内有效
- 成绩持续收录中，如有漏收或登记有误，欢迎直接联系 UP 主

## 页面板块

| 板块 | 说明 |
|---|---|
| 赛事起源 | 杯赛的由来 |
| 杯赛目的 | 娱乐 + 玩梗 |
| 免责声明 | 规则性质、参考价值说明 |
| 关于规则 | 规则以原版视频为准 |
| 关于收录 | 收录方式与遗漏说明 |
| 完整成绩 | 全部成绩表格，可按角色搜索 |
| 想了解单通哥 | 相关视频 |

「单通哥系数」= 本条 DPS ÷ 62,366（单通哥那条），纯整活指标，仅显示 ≥1 的记录。
